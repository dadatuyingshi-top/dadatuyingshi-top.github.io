// 01 · DADA SPIRIT

达达 精神

达达主义诞生于一战时的苏黎世咖啡馆，核心主张是反叛一切既成规则。我们用同样的态度看电影——不看评分、不听宣传、不跟榜单，只看它有没有让你在某个瞬间真正愣了一下。

反套路 片单

// 03 · SKIP GUIDE

跳集 指南

长剧注水是全球性问题，不是你的错。学会跳集，是当代观众最该掌握的基本技能之一。

🦘

前 20 分钟原则

任何片子给二十分钟。二十分钟后还进不去，就换。这不是没耐心，是尊重时间。

20 MIN RULE
📊

看集评再跳集

先看单集评论再决定要不要看。社区里的集评往往比总评更诚实。

EP REVIEWS
🧵

主线优先

支线可以跳，人物弧光不能断。跳之前先搞清楚这条线回不回得来。

MAIN THREAD
🍿

情绪价值优先

今天只想放空，就看不需要动脑的。选片要考虑当下的状态，不是越难越好。

VIBE FIRST
